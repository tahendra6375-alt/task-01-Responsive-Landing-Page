# Task 01: Responsive Landing Page

A clean, modern, and highly aesthetic landing page built with fluid responsiveness at its core. The page seamlessly scales down from large desktop monitors to tablets and mobile screens.

## Features
* **Fluid Layouts:** Uses relative units, Flexbox, and CSS Grid to ensure pixel-perfect scaling across device widths.
* **Mobile Navigation:** Interactive menu toggle implemented using lightweight JavaScript.
* **Clean Typography & UX:** Optimized text contrast and modern layout structures to keep users engaged.

## Tech Stack
* HTML5 (Semantic Structure)
* CSS3 (Media Queries, Flexbox, Grid)
* Vanilla JavaScript (DOM toggles)

## How to Run
Open `index.html` directly in any web browser, or use the VS Code **Live Server** extension for real-time development reloading.
